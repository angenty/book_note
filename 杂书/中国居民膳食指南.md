# 中国膳食指南

## 准则一：食物多样，合理搭配

### 谷薯类食物

谷薯类食物主要包括以下几类：
#### 谷物类

- **稻米类**：大米、糯米、糙米、黑米、红米等
- **麦类**：小麦、面粉、全麦粉、燕麦、大麦、黑麦、荞麦等
- **玉米**：玉米面、玉米碴、爆米花等
- **小米**：黄小米、糯小米等
- **高粱**：红高粱、白高粱等
- **其他**：青稞、藜麦、黑米等
#### 薯类

- **马铃薯**（土豆）
- **甘薯**（红薯、地瓜、白薯、紫薯）
- **芋头**（香芋、毛芋）
- **山药**（淮山、铁棍山药）
- **木薯**
- **魔芋**
#### 杂豆类（常作为主食）

- 红豆、绿豆、黑豆、芸豆、豌豆、蚕豆等
#### 加工制品

- 馒头、面条、米饭、面包、饼干、麦片、粉丝、粉条、年糕、汤圆等

### 常见的全谷物

- **全麦**（完整小麦粒）
- **糙米**（仅去除外壳，保留米糠层和胚芽）
- **燕麦** 燕麦片、钢切燕麦）
- **玉米**（整粒玉米、玉米碴）
- **小米**、**高粱**、**荞麦**、**黑米**、**藜麦**等

#### 为什么推荐吃全谷物

| 营养成分         | 全谷物优势               |
| ------------ | ------------------- |
| **膳食纤维**     | 含量是精制谷物的3倍以上，促进肠道健康 |
| **B族维生素**    | 胚芽和麸皮富含维生素B1、B2、烟酸等 |
| **矿物质**      | 镁、铁、锌、硒等含量更高        |
| **植物化学物**    | 含有抗氧化物质如酚类化合物       |
| **升糖指数(GI)** | 更低，血糖波动更平稳          |
